# Roadmap

## Phase 1 — Foundation

Swift Package, project contract, CI-ready module boundaries, and repository hygiene.

## Phase 2 — State engine

Versioned snapshots and profiles, capability metadata, diffing, and deterministic plans.

## Phase 3 — simctl and CLI

Typed process execution, inventory parsing, safe mutations, snapshot/diff/plan/apply.

## Phase 4 — MCP

New and legacy protocol compatibility over stdio, typed tools, confirmation gates.

## Phase 5 — Open-source release

Bilingual documentation, examples, security policy, contribution workflow, CI.

## Later

- Native SwiftUI companion app.
- Profile layers and reusable presets.
- App container snapshots and richer best-effort device settings.
- Homebrew distribution and signed release artifacts.
